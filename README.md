# ヴァンパイアサバイバーライクゲーム

ブラウザで動作するヴァンパイアサバイバー風のゲームです。

## 遊び方

1. ブラウザで `index.html` を開く
2. 「ゲームスタート」ボタンをクリック
3. プレイヤーを操作:
   - **PC**: WASD キー
   - **スマホ/タブレット**: 画面をタッチ&ドラッグ
4. 敵を倒して経験値を獲得
5. レベルアップ時にアップグレードを選択

## 自機の画像を変更する方法

プレイヤーキャラクターの見た目を好きな画像に変更できます。

### 手順

1. 好きな画像ファイル（PNG、JPG など）を用意
2. 画像ファイルをプロジェクトフォルダに配置（例: `player.png`）
3. `game.js` の6行目を編集:

```javascript
const playerImagePath = 'player.png'; // ← ここを画像ファイル名に変更
```

### 例

- `const playerImagePath = 'my-character.png';` - my-character.png を使用
- `const playerImagePath = 'images/hero.jpg';` - images フォルダ内の hero.jpg を使用
- `const playerImagePath = null;` - 画像を使わず四角形で描画（デフォルト）

### 推奨画像サイズ

- 正方形の画像（例: 32x32、64x64、128x128 ピクセル）
- 背景が透明な PNG 形式が最適

画像が見つからない場合は、自動的に緑色の四角形で描画されます。

## ゲーム機能

- 自動攻撃システム
- 敵のAI（プレイヤーを追跡）
- レベルアップとアップグレードシステム
- 体力バーと経験値バー
- スコアと生存時間の記録
- 時間経過で難易度上昇

## モバイル対応

このゲームはスマートフォンやタブレットでもプレイ可能です。

### タッチ操作

- **移動**: 画面をタッチ＆ドラッグすると、タッチした位置にプレイヤーが移動します
- **攻撃**: 自動で最も近い敵を攻撃します
- **レベルアップ**: 画面上のアップグレードボタンをタップして選択

### 推奨環境

- iOS Safari
- Android Chrome
- タブレット端末
- レスポンシブデザインで画面サイズに自動対応
